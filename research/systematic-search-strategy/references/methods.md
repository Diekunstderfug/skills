# 检索方法：按任务需要读取

## 词汇与树

从研究问题提取概念，先判断概念是否必须出现在检索记录中。干预问题可用 PICO 辅助；暴露问题可用 PECO，范围问题可用 PCC。框架辅助理解，不决定固定的 AND 块数量。年龄阈值、结局、比较组等可能只在全文中出现，应说明何时留到筛选。

每个重要概念：

1. 用当前 NLM MeSH Browser 或 MeSH lookup／RDF 接口查询候选词，检查正式名称、Descriptor ID、Scope Note、Entry Terms 和相关树号。若是 Supplementary Concept，核实其类型和映射主题词，不当作 Descriptor。
2. 核对与问题有关的上位／下位关系。一个词可以有多个树位置；只展示有关分支。默认展开下位主题词时，检查是否引入不合范围的分支，再决定是否需要 `:noexp`。`[majr]`、子主题词等限制要有实际理由。
3. 将合适的入口词、作者用语、缩写、历史称谓、拼写、连字符和词形变体列为自由词候选。词义不明或未核实的词标注状态，不虚构 MeSH ID 和树号。

**默认关键词树是检索分组图，不是完整官方 MeSH 树。** 区分两种关系：

```text
概念 A（检索概念，不是官方主题词）
├─ MeSH：核实后的名称 [ID；来源链接]
│  └─ 相关下位主题词：仅在官方层级已核实时展示
└─ 自由词候选（OR）：入口词、作者用词、缩写、拼写变体

概念 B
├─ MeSH：核实后的名称／暂无合适词
└─ 自由词候选（OR）：……
```

入口词属于同义表达，不应画成独立下位主题词。采用文本树即可，按用户语言解释，检索词保留原文。用户明确要官方 MeSH tree 时，以核实的层级和树号为主体，另列自由词。

组合示意（占位符须换成已核实词汇，不能直接执行）：

```text
("正式主题词 A"[mh] OR "自由词 A1"[tiab] OR "自由词 A2"[tiab])
AND
("正式主题词 B"[mh] OR "自由词 B1"[tiab])
```

不存在合适 MeSH 的概念可仅用自由词。补充概念使用当前 PubMed 支持的相应字段并实测。简单任务不必把全部候选词及取舍表展示给用户。

## 基础校验

- 检查括号、引号、字段与 AND/OR 分组；每个词的字段作用范围清楚。不要仅因为结果多就加结局、语言、年龄或全文可用性限制。
- 数字年龄优先用年龄短语或平台支持的邻近表达，不把裸数字与 `age/year*` 在整篇摘要中任意 AND：数字可能是样本量、随访年限、剂量或生存率。抽查年龄是否指患者确诊年龄；`child*` 也可能是成年人的童年暴露。宽年龄主题词／自由词必要时另留补查层，不因种子全部命中就认为没有新增漏检。
- 跨库转换先核对该平台的实际字段及匹配/排序方式，再读少量题名摘要检查必要概念；HTTP 200、无警告和原样回显都不能证明字段被正确应用。关键词、全文、书目相关性检索的命中数不等价于主题适格文献数。
- 核对当前平台语法。PubMed 截词首个 `*` 前需要至少 4 个字符；字段、引号、截词可能改变自动映射。邻近检索不能与表达式内部的截词混用；`:~0` 允许词序变化，不等价于固定顺序的精确短语。
- 查看 PubMed Search Details 或 ESearch 的 `querytranslation`、`warninglist`、`errorlist`。分别理解短语索引、未知字段、实际零命中和网络失败，不能从一个短语警告推断该词无检索价值。
- 用最终检索式做计数或小样本请求，必要时单独测试有问题的词／概念块。若某词可能被删除，先看独立结果、实际解析及删除前后差异；保留语义正确且适合后续更新的零命中词，并简要注明。
- 已有相关 PMID 且核对成本很低时，可顺便验证是否被主题检索式命中；没有种子就继续，不强制另找种子。直接按 PMID 找到文章不算主题检索命中。
- 报告实际检查范围，例如“结构已检查；MeSH 已核实；PubMed 实测 N 条，日期……；尚未验证种子召回”。N 只能来自执行结果。离线时提供可用草稿并明确未做的在线校验。

这些是可执行的基本检查，不要求为每项生成单独报告。复杂词义或漏检问题可按需使用下述诊断，不自动展开整套正式流程。

## 检索记录与续接

普通检索和正式综述都保留执行记录。使用用户研究目录中的现有记录，或建立一份 `search-log.md`；只查词且未运行文献查询时，可在回复中保留词汇来源而不创建文件。若目录不可写，先给可保存的记录并说明未落盘，不声称已保存。

最小记录包括：

- **范围与策略版本**：研究问题、当前边界、各库完整实际查询及重要改动理由。修改式子保留原版本，避免新查询覆盖旧计数。
- **来源进度表**：数据库及平台、查询版本、执行时间、状态、命中数、已取回数、结果位置、缺口与下一步。数值未知写未知；未执行写未执行。状态区分计划中、运行中、完成、零命中、部分完成、失败、不可访问、有理由未执行。
- **续接位置**：分页／游标／分片（接口支持时）、已完成批次、已取回标识及失败原因；过期游标说明重跑和去重方式。只有计数或小样本时标明，不能标作全部结果已下载。
- **缺口**：尚未检索的相关来源、未解决的词汇／解析问题、已知漏检文献、下载上限及访问限制。没有种子时写“文献漏检未验证”，不能把空表当作没有遗漏。

首次执行前记录来源计划；每个来源、可恢复批次或查询版本结束后更新；失败和中断也及时记录。引用工具已保存的原始结果／分页文件，无须再制作重复报告。查询记录不写入 API 密钥或私人连接参数。

用户说“继续”时先读记录，沿用有效结果，优先处理未完成来源和已知缺口。仅在查询变更、结果过期或错误需要时重跑，并留下原因。更多数据库属于覆盖策略，不能用数据库数量证明查全；不同接口可能覆盖同一文献库，记录重叠与新增来源。

## 正式综述扩展

仅用于 SKILL.md 指定的正式任务；按适用性完成，不把指南的某一研究类型要求套给所有问题。

- **策略设计**：按 Cochrane 方法选择必要概念并结合主题词与自由词。核实研究设计过滤器的来源、版本和平台，不自制“已验证过滤器”；CENTRAL 不另加 RCT 或 human 过滤器。
- **覆盖**：尽量搜相关数据库、适用注册平台和补充来源，记录零结果和访问缺口。需要时做前向／后向引文追踪。未取得的订阅库结果不能声称已检索，也不以开放数据库替代后宣称覆盖等价。
- **种子验证**：独立于待测检索式确定适格且在目标库中的种子；区分用于扩词和用于验证的记录。逐篇分析未收录、范围外、词汇遗漏、过窄 AND／过滤器、解析问题或下载缺口。报告分子／分母，不当作总体召回率；由类似文章扩展出的集合须先筛选，不能自动充当金标准。
- **可选差集诊断**：对词汇敏感或漏检难解释的概念，比较 `(MeSH) NOT (自由词)` 与反向差集，读样本找遗漏或歧义。诊断用 NOT 不进入最终式；没有合适的两层词汇时不适用。不要求每个简单概念都做。
- **PRESS 自查／同行审查**：分别查看问题转换、布尔与邻近算符、主题词、自由词、拼写／语法／行号、限制与过滤器。记录实际审查者和方式；AI 自查不等于独立同行审查。
- **PRISMA-S 记录**：沿用官方清单，在一个文件中合并数据库及平台、其他来源与检索方式、各库完整实际检索式、日期、限制及依据、借鉴策略／过滤器、修订和更新、审查方式、每个来源的记录数与去重方法。不把此摘要当作已完成全部 16 项核查。
- **执行核对**：记录总命中、取回数、唯一标识数、分页／上限和失败重试；无总数时说明无法数值核对。完整下载与策略覆盖是不同问题。未经执行的计数、筛选数、验证和限制都不能补写成已完成。
